# Somayah Nouruzi Portfolio

Personal portfolio site for Somayah Nouruzi, Digital Product Manager.

Live site: https://somayahnouruzi.com

## About

The site covers how I create value, my focus areas, how I work, and case studies that show my product thinking across agentic AI experiences, enterprise workflows, and consumer tools.

## Contents

- `index.html`: the full site in a single file (HTML, CSS, and JavaScript together)

## Tech

- Plain HTML, CSS, and JavaScript with no build step
- Fonts from Google Fonts (Bricolage Grotesque and DM Sans)
- Light and dark mode
- Hosted on GitHub Pages

## Run locally

Download or clone the repo and open `index.html` in a browser.

## Update the site

Edit `index.html` and commit the change. GitHub Pages redeploys automatically within a few minutes.
